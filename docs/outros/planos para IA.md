# Planos para IA

Pacote de fundacao muito forte:

- Cone = "zona de ameaca / intencao" (mais preciso, mais caro)
- Retangulo = "busca rapida / broad-phase" (barato e amplo)
- Path real por cima = validacao visual de que o envelope faz sentido

Isso vira:
- ferramenta de balanceamento
- ferramenta de tutorial
- e depois cerebro da IA

Ideias extras:
- Prioridade de alvo por risco: cruzar cone/retangulo com HP/combustivel para decidir focos.
- Custo de manobra: escolher paths que minimizem exposicao ao cone inimigo.
- Assistente de IA: sugerir manobras quando o player esta dentro do cone rival.
- Auto-ajuste de dificuldade: abrir/fechar o cone para simular pilotos mais/menos precisos.
